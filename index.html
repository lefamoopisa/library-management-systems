Open the Community Library website

This project uses a Node.js server and database for accounts, shared inventory, supplier orders, and live members. A standalone HTML file cannot start those services.

To run locally: open this project folder in VS Code, run npm install once, then npm start and open the local address printed in the terminal.

To share online: publish the source on GitHub, deploy it to Render using the included render.yaml, and share the live website URL. The GitHub repository link and this file are not the running website.
